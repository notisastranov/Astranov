## What SpaceNet is

SpaceNet is an internet operating system that depicts everything in space: research, calls, orders, harbors, and delivery as pins and great-circle hops on a live Earth. Street maps are a zoom-in, not home. It is already running. Guests locate, sign in with Google, and name a place, a thing, or an order.

It is built by a human architect plus Grok Build (code) plus an in-app Grok unit (voice + research) plus real user sessions. Usage statistics already ship to a live bridge so the next fix is chosen from how people actually use the planet OS.

## The problem with today's hosts

Vercel, GitHub, and static CDNs treat an application as a frozen tree of files. That was correct for websites. It is wrong for SpaceNet.

A living OS changes while people use it. Agents write code. The unit files faults. Guests run scenarios. The next version should land without a human waiting on a static deploy queue. Today's stack forces: edit → commit → wait → hope cache dies. The product freezes between those ticks.

## What we are asking SpaceX to build with us

A **dynamic hosting plane** for extreme, collectively evolved applications:

1. **Fluid runtime** — the running app is the source of truth. Agents patch modules in place. Git is the ledger, not the only gate.
2. **Collective intelligence loop** — human intent + in-app AI + coding agent + usage packets share one inbox. Failures become the next ship automatically.
3. **Space-native deploy** — Earth is the UI; orbit/field/street are zoom tiers. Hosting must understand spatial objects (pins, arcs, live calls), not only HTML routes.
4. **Any-path mesh** — Starlink, 5G, Wi-Fi, mesh radios. The OS already thinks in packets, not a single ISP.
5. **Safety** — signed agent writes, owner keys, rollback in seconds, no silent overwrite of money or identity.

SpaceNet is the first tenant and the proof. The king of this class of application. We are not asking for a free launch. We are asking for a 30-minute working session with whoever owns Starlink product, xAI product, or the consumer surface — to design this plane together.
